# Funciones del Corte 2

75 ejercicios de `invente`/`devuelva`, organizados por dificultad. Todos se
ejecutan desde la raíz del proyecto y no escriben archivos:

```bash
python3 src/cli/main.py ejercicios/corte2/funciones/faciles/F03_suma_dos.arepa --ejecutar
```

| Carpeta | Rango | Contenido |
|---|---|---|
| `faciles/` | F01-F25 | funciones sin parámetros, aritmética, lógica, conversiones y una llamada |
| `medianos/` | M01-M25 | condicionales, composición, closures, funciones dentro de `cree`/filtros y tablas |
| `dificiles/` | D01-D25 | recursión (factorial, Fibonacci, MCD, Collatz), recursión mutua y cadenas de llamadas |

Índice general de ejercicios: [`../../README.md`](../../README.md).
Regresión completa: `bash herramientas/regresion_programas.sh`.
