# Ejercicios del Corte 3

12 programas de visualización: las cinco gráficas, sus cláusulas de estética y
las dos formas de exportar (`guardela` y `muestrela`). Índice general:
[`../README.md`](../README.md).

| Ejercicio | Tema |
|---|---|
| `G01_barras_ciudad` | barras con agrupación |
| `G02_lineas_dos_series` | varias series con `ejey [a, b]` |
| `G03_histograma_unidades` | histograma de una columna |
| `G04_dispersion_precio` | dispersión numérica |
| `G05_cajas_ciudad` | cajas por categoría repetida |
| `G06_estetica_completa` | título, ejes y leyenda |
| `G07_muestrela` | salida automática en `salidas/` |
| `G08_pipeline_grafica` | flujo completo hasta el PNG |
| `G09_serie_temporal` | eje x continuo año-mes |
| `G10_cajas_decadas` | agrupación por número repetido |
| `G11_histograma_ingresos` | histograma de columna calculada |
| `G12_cinco_graficas` | las cinco gráficas juntas |

```bash
python3 src/cli/main.py ejercicios/corte3/graficas/G01_barras_ciudad.arepa --ejecutar --sin-ventana
```
