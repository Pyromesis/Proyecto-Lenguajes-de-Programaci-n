# Datos de los ejercicios

Casos borde usados por los ejercicios del lector CSV propio:

| Archivo | Contenido | Ejercicios |
|---|---|---|
| `vacia.csv` | solo encabezado, sin filas | D11 |
| `comillas.csv` | comillas, comas y saltos dentro de campos | D08 |

Los conjuntos generales (`ventas.csv`, `empleados.csv`, `encuesta.csv`) viven
en `datos/` en la raíz del proyecto. El caso de estudio usa
`caso_estudio/datos/pasajeros.csv`.
